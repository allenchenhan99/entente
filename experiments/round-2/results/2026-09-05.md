## What the numbers say

- **P4 is the clean result**: with the decision missing, native is a coin flip (1/2) and Entente is 2/2 because the
  agent asks and the answer comes back through the contract. This is PRD §2.2 in one table.
- **P1 and P3 did not separate the arms**: with a 30-turn history Claude extracts the final decision and honours a
  "do not reuse customer data" instruction on its own. The advantage of distillation and bounded context needs
  histories that do not fit, or contradictions that are not spelled out as "final answer".
- **P2 exposed a real product gap**: two parallel contracts that share an interface cannot be verified independently
  when one's tests import the other's file. Options: a `verify_with: [sibling]` field that merges verified sibling
  branches into the worktree before checks, or lint that refuses a contract importing a path outside its own
  worktree without a dependency.
- **Cost**: Entente is 3–5× wall-clock and roughly 3× uncached input on P4 (handshake + questions + progress reports);
  Codex asks far more questions than Claude (26 vs 3) — the bootstrap prompt should cap rounds.

## Harness bugs found and fixed while running (all on main)

1. Integration check ran in `<relayDir>/wt/integration`, which does not exist when RELAY_DIR is outside the repo.
2. Codex paste acceptance: footer-first repaint, raw paste before the placeholder, spinner never quiet — three
   false "accepted" verdicts; fixed with a settle window, double verdict, and reading the busy line directly.
3. Claude Code trust dialog: trust was written for `/tmp/…` but Claude keys by the real path `/private/tmp/…`.
4. Declared-tier delivery: an agent silent for 45 s after its prompt now gets Enter pressed for it (×3), then the task
   blocks on the human. It rescued the Codex P4 run.

## Follow-ups
