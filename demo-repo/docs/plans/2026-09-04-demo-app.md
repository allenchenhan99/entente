# Demo Application Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Build a standalone, deliberately unsigned-in Node.js and TypeScript demo application with deterministic in-memory collaborators and a reproducible repository initializer.

**Architecture:** Keep domain behavior in three small in-memory modules and expose read-only HTTP endpoints through Hono. Tests call the real modules and `app.request()` directly; time is injected into the session store so expiry tests are hermetic. Shell scripts verify the nested package and copy it into a one-commit standalone repository.

**Tech Stack:** Node.js 22, TypeScript/NodeNext, Hono, `@hono/node-server`, Vitest, tsx, zod.
